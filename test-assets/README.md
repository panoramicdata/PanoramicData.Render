# Test Assets

This directory contains test documents and reference images for visual regression testing.

## Structure

```
test-assets/
├── docx/           # Source DOCX files for testing
├── reference/      # Reference PNGs generated by Word (ground truth)
└── README.md       # This file
```

## Generating Reference PNGs

Reference PNGs are generated using the `PanoramicData.Render.ReferenceGenerator` console app,
which uses Microsoft Word Interop to render DOCX → PDF, then PDFtoImage (PDFium) to rasterize
PDF → PNG at 150 DPI.

### Prerequisites

- Microsoft Word installed on the machine
- Windows (COM Interop requirement)

### Usage

```bash
# From the repo root
dotnet run --project PanoramicData.Render.ReferenceGenerator -- test-assets/docx test-assets/reference
```

### Output Naming Convention

`{docx-stem}_page-{N}.png` where N is the 1-indexed page number.

For example, `basic-text.docx` with 2 pages produces:
- `basic-text_page-1.png`
- `basic-text_page-2.png`
